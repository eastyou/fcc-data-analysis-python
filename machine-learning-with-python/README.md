# freeCodeCamp — Machine Learning with Python Projects

Certification projects for freeCodeCamp's **Machine Learning with Python** curriculum (TensorFlow / Keras).

| Project | Entry point |
| --- | --- |
| Rock Paper Scissors | `rock-paper-scissors/RPS.py` |
| Cat and Dog Image Classifier | `cat-and-dog-image-classifier/fcc_cat_dog.py` |
| Book Recommendation Engine using KNN | `book-recommendation-engine-using-knn/book_recommendation_knn.py` |
| Linear Regression Health Costs Calculator | `linear-regression-health-costs-calculator/fcc_predict_health_costs_with_regression.py` |
| Neural Network SMS Text Classifier | `neural-network-sms-text-classifier/fcc_sms_text_classification.py` |

Datasets are the ones provided by freeCodeCamp for each project (cats_and_dogs_filtered, books.csv, ratings.csv, insurance.csv, SMS spam collection).

## Run

```bash
python3 -m pip install -r requirements.txt
cd rock-paper-scissors && python3 -c "import RPS"
```
