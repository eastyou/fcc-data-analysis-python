Introduction

FocusFlow exposes a small HTTP API for starting, pausing and summarising focus sessions.

Every endpoint returns JSON and requires an API key in the request header.

GET /v1/sessions
  • Base URL: https://api.focusflow.dev
  • Auth header: X-API-Key
Installation

Install the command line helper with your package manager of choice.

npm install -g focusflow-cli

Then authenticate once with your personal token.

focusflow login
  • Node.js 18 or newer
  • An active FocusFlow account
Basic Usage

Start a session and read its state. Sessions accept an optional label.

focusflow start --label "Write report"

You can pause, resume and stop a session at any time.

focusflow pause
  • start — begin a new session
  • pause — suspend the current session
Error Handling

All errors include a machine-readable code and a human-readable message.

{ "code": "SESSION_NOT_FOUND", "message": "No active session" }

Retry only on 5xx responses, and back off exponentially.

Retry-After
  • 400 — invalid request
  • 401 — missing or invalid API key
FAQ

Can I use the API from the browser? No, requests must come from a server.

Is there a rate limit? Yes, 120 requests per minute per key.

429 Too Many Requests
  • Docs are versioned with the API
  • Breaking changes ship under a new version
