# freeCodeCamp — Data Analysis with Python Projects

Certification projects for freeCodeCamp's **Data Analysis with Python** curriculum.

| Project | Entry point |
| --- | --- |
| Mean-Variance-Standard Deviation Calculator | `mean-variance-standard-deviation-calculator/mean_var_std.py` |
| Demographic Data Analyzer | `demographic-data-analyzer/demographic_data_analyzer.py` |
| Medical Data Visualizer | `medical-data-visualizer/medical_data_visualizer.py` |
| Page View Time Series Visualizer | `page-view-time-series-visualizer/time_series_visualizer.py` |
| Sea Level Predictor | `sea-level-predictor/sea_level_predictor.py` |

Each folder contains the notebook-style module described by freeCodeCamp plus the CSV dataset the module reads.

## Run

```bash
python3 -m pip install -r requirements.txt
cd demographic-data-analyzer
python3 demographic_data_analyzer.py
```
